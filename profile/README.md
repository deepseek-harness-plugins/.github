我们围绕 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 收集和维护社区插件，关注会话导航、阅读体验与交互效率。欢迎一起完善插件、文档和使用体验。

## 参与共建

- **推荐插件或改进首页**：在 [组织首页仓库](https://github.com/deepseek-harness-plugins/.github/issues) 提交建议。
- **改进插件**：在对应仓库提交 Pull Request，说明使用场景、改动内容与验证结果。

感谢原作者和社区贡献者。各插件的版权与许可证以对应仓库为准，欢迎向上游贡献改进。
